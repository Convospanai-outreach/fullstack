# Benchmarks and targets

Empty until the benchmark audit runs. Do not fill any cell from memory or estimate.
Every baseline is measured in this app; every target is approved by the human.

North-star: time from signup to first approved draft.

| Measure | Baseline | Target | Benchmark it follows | Measured on |
|---|---|---|---|---|
| Steps from signup to first approved draft | not measured | | | |
| Required fields on that path | not measured | | | |
| Clicks from Home to approving a draft | not measured | | | |
| Home load time | not measured | | | |
| `/api/dashboard/summary` response time | not measured | | | |
| Screens with no empty state or no error state | not measured | | | |

## Rules

- Benchmark behaviour and numbers, never another product's look, layout, wording or brand.
- Verify a benchmark pattern on the live product or its public docs before citing it.
- The human approval step is deliberate. No "fewest clicks" target may weaken it.
