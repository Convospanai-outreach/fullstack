# ConvoSpan V1 Beta Scope

## Goal

Launch the smallest stable version of ConvoSpan as an email-first outreach workspace.

## In Scope

- account and team setup
- brand identity
- email sending configuration
- AI-assisted drafting
- lead import
- campaign creation
- approvals-first launch flow
- billing
- support and help center

## Out Of Scope For Beta

- LinkedIn automation
- browser-node execution
- edge runtime deployment
- omnichannel workflows
- marketplace and agent-builder surfaces
- public autonomy claims

## Deployment Target

- `apps/web` on Railway
- `apps/api` on Railway
- `postgres` private on Railway
- `redis` private on Railway
- no `edge-fastapi` deployment for the first beta unless a design partner requires it
