# Magnet formats

Per-format effort, payoff, and the failure mode that kills it — plus build
specs and the diagnostics for judging a live magnet. Every format trades
between volume (how many opt in) and warmth (how ready they are to buy);
payoff notes name the trade.

## Choosing a format

Match what the buyer needs at the moment of opt-in, not what's easiest to make:

| The buyer needs… | Build a… |
|---|---|
| To not miss steps in a process they already run | Checklist |
| A lookup they'll return to (formulas, shortcuts, prompts) | Cheat sheet |
| A deliverable they produce anyway (proposal, plan, tracker) | Template |
| Proof of what good looks like, with the why | Swipe file |
| To be taught over days — trust before a considered purchase | Email mini-course |
| A number: what this costs, saves, or earns for them | Calculator |
| To know where they stand and what's weak | Grader or quiz |
| A usable draft artifact generated from a few inputs | Generator |
| Objections answered live | Workshop / webinar |

## Checklist

- **Effort**: hours.
- **Payoff**: highest opt-in rate of any content format — near-zero commitment
  to consume. High volume, low-to-mid warmth.
- **Fails when**: items are judgment calls ("optimize your headline") instead
  of verifiable actions with a done-state.
- **Build**: 1–2 pages. Verb-first items, each checkable ("Set explicit
  preview text," not "think about preview text"). Group by workflow order past
  ten items. Printable layout. The last item is the bridge.

## Cheat sheet

- **Effort**: hours.
- **Payoff**: gets kept — pinned, printed, re-opened — so the brand earns
  repeat exposure. Conversion behaves like a checklist's.
- **Fails when**: it's a compressed article — paragraphs to read instead of a
  grid to scan.
- **Build**: one page. Tables, grids, columns; organized for lookup (by task,
  not by concept); bold the five highest-use entries.

## Template

- **Effort**: hours–days.
- **Payoff**: the best warmth of the cheap formats — whoever wants your
  proposal template writes proposals for a living. Medium volume, high
  buyer-match.
- **Fails when**: it arrives empty, or takes more than five minutes to adapt.
- **Build**: pre-fill one complete worked example; [BRACKET] the slots to
  customize; first page or tab is "use this in 5 minutes"; in spreadsheets,
  lock formula cells and leave inputs open.

## Swipe file

- **Effort**: days — curation is the work.
- **Payoff**: high shareability; positions taste and judgment, which suits
  services where judgment is the product.
- **Fails when**: collection without annotation. The "why this works" note is
  the product; the examples are just evidence.
- **Build**: 15–50 examples grouped by use case. Each: the example, 2–3
  bullets on why it works, one line on how to adapt it. Credit every source.

## Email mini-course

- **Effort**: days.
- **Payoff**: lowest opt-in of the content formats, best-warmed leads — they
  read you several times before any pitch, and delivery doubles as nurture.
- **Fails when**: lessons withhold ("more on this in lesson 4") or the cadence
  crowds the inbox.
- **Build**: 3–5 emails over 5–7 days. Each lesson standalone: teach → worked
  example → one exercise. Final email recaps and makes the bridge.

## Ebook / guide

- **Effort**: weeks — the worst effort-to-consumption ratio in the library,
  and the default people reach for anyway.
- **Payoff**: authority positioning; decent volume, lowest consumption.
- **Fails when**: chosen by default. Justified only when depth is the
  differentiator — original research, proprietary data, a definitive
  reference.
- **Build (if justified)**: under 25 pages; findings first, method after; a
  takeaway box per chapter; a summary page that stands alone when shared.

## Quiz / assessment

- **Effort**: days.
- **Payoff**: highest completion-to-email conversion (sunk cost — they want
  their result), and answers segment the list from day one.
- **Fails when**: results read as horoscopes — flattering type-names with no
  verdict and no next actions.
- **Build**: 5–10 multiple-choice questions that feel diagnostic (each maps to
  a scoring dimension); 3–5 result types, each a named diagnosis plus 2–3
  actions specific to it; quiz ungated, result teased on-page, full result
  delivered by email.

## Calculator

- **Effort**: days — a single self-contained HTML file.
- **Payoff**: decision-stage leads (someone pricing a change); verdicts get
  shared internally to make the case; the page can earn "[thing] calculator"
  searches.
- **Fails when**: black-box math — show the formula and assumptions, the
  credibility is the point — or inputs the user can't answer without research.
- **Build**: ≤5 inputs they know cold; output = verdict + breakdown; defaults
  pre-filled so it works on first paint; email-gate the detailed report
  (assumptions, line items, PDF), never the headline number.

## Grader / audit

- **Effort**: days–weeks.
- **Payoff**: curiosity-driven usage ("how do we score?") that manufactures
  awareness of the exact problem the paid thing fixes.
- **Fails when**: a naked score — "61/100" with no benchmark and no fix list
  is a shrug.
- **Build**: score + benchmark ("median in your bracket: 74") + top-3 fixes
  on-page; full fix list by email. Re-grading after fixes is a built-in return
  visit.

## Generator

- **Effort**: days–weeks.
- **Payoff**: tangible artifact plus repeat usage; strong shareability.
- **Fails when**: output needs heavy editing before it's usable — that's a
  template wearing a tool's costume; ship the template instead.
- **Build**: few inputs → one complete draft artifact; copy/export built in;
  gate premium variants or bulk output, never the first result.

## Workshop / webinar

- **Effort**: recurring — prep, delivery, follow-up. Highest cost per lead.
- **Payoff**: highest trust per lead; fits right before considered purchases.
- **Fails when**: it's a pitch wearing a lesson. Teach for real; sell in the
  final tenth.
- **Build**: 30–40 minutes of teaching + Q&A; replay gated behind
  registration; follow-up with replay + summary + bridge within 24 hours.

## Diagnostics

First check the opt-in rate against placement, then read the pattern.

| Placement | Healthy opt-in range |
|---|---|
| Dedicated page, warm traffic (list, profile links, referrals) | 20–40% |
| Dedicated page, cold traffic (ads) | 10–25% |
| Content upgrade inside a relevant post | 3–8% of readers |
| Exit or scroll popup | 2–5% of visitors |
| Site-wide banner or sidebar | 0.5–2% |

| Signal | Meaning | Move |
|---|---|---|
| Opt-in below range | Promise or page problem | Sharpen the name and promise first — rename before rebuild; page copy → copywriting skill |
| Opt-in fine, leads inert (first-3-email opens well under ~40%, no bridge-step take-up within 90 days, poor buyer-profile match, disposable addresses) | Wrong-list magnet | Re-derive from the paid thing; narrow to a promise only a buyer would want |
| Low volume, strong engagement | Right magnet, wrong reach | More placement and traffic, sharper name — don't touch the asset |
| High tool usage, few emails | Gate in the wrong place | Move value into the emailed report; keep the tool itself ungated |
