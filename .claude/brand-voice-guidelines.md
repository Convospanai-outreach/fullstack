# CraftMyFunnel — Brand Voice Guidelines

Governed funnel workflows for operators, not demos.

---

## We Are / We Are Not

| We Are | We Are Not |
|---|---|
| **Governed, controlled, approved-before-send** | Autonomous / "AI does it all" |
| **Blunt about the problem** (*"Signals disappear. Follow-ups stall. Deals die."*) | Soft, apologetic, hedge-y, therapy-speak |
| **System-of-layers thinker** (*signal → outreach → human → edge → revenue*) | Feature-list thinker |
| **Built for operators running real B2B service teams** | Built for demos / hype |
| **Trust and data sovereignty as a selling point** | Vague on data handling |
| **Short punchy fragments, staged/numbered structure** | Long flowing generic paragraphs |

---

## Tone by Context

| Context | Tone & Style |
|---|---|
| **Problem statements** | Blunt, short sentences, cold diagnosis. |
| **Product layer descriptions** | Confident, plain verbs (*drafts, tracks, governs, routes, surfaces*). |
| **CTA / pilot invite** | Direct, scarcity-flavored (*"invite-only," "small group"*). |
| **Trust/security** | Serious, exact, no jokes. |
| **Tagline** | Terse manifesto: *"Built for operators, not demos."* |

---

## Core Voice Traits

1. **Governed** — The central keyword of the brand. Nothing ships unchecked.
2. **Terse fragments** — Headlines read like commands or diagnoses, not marketing fluff.
3. **Problem-first** — Always names the pain before presenting the fix.
4. **No adjective inflation** — Never use "revolutionary," "seamless," "cutting-edge," "effortless," or "AI magic." Use plain verbs instead.
5. **Operator-speak** — Speaks to people who manage pipeline and quota, not buyers who need hype.

---

## Vocabulary Standard

- **Required Vocabulary**: `governed`, `signal`, `approved`, `drafts`, `routes`, `surfaces`, `stage`, `pipeline`, `operators`
- **Strictly Banned**: `seamless`, `revolutionary`, `game-changing`, `effortless`, `AI-powered magic`, `auto-pilot`

---

## Seth Godin Style Framework

- Cut therapy-speak (*No "You want X, not Y"*).
- One idea per line.
- Truth stated flat.
- Every answer roots back to "governed" and operator control.
